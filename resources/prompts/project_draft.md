Aus einem kurzen Projekteintrag soll eine ausführliche Fassung für eine
Projektliste werden — auf Deutsch UND auf Englisch.

TITEL: {{ title }}
KURZBESCHREIBUNG: {{ summary }}
TAGS: {{ tags }}
NOTE: {{ grade }}

BEREITS ERFASST (übernimm diese Angaben, statt neue zu erfinden):
{{ existing }}

Regeln:

- Erfinde nichts. Auftraggeber, Zeitraum und Teamgröße bleiben leer, wenn sie
  sich nicht aus dem Text oben ergeben. Eine Projektliste mit erfundenen Fakten
  ist schlechter als eine mit Lücken.
- Leite das Ergebnis nur aus Belegbarem ab (eine Note, ein Hackathon-Sieg, ein
  ausgelieferter Prototyp). Keine erfundenen Prozentzahlen.
- Der deutsche Block ist vollständig auf Deutsch, der englische vollständig auf
  Englisch. Die englische Fassung ist eine Übersetzung derselben Aussagen,
  kein anderer Text.
- Produkt-, Werkzeug- und Firmennamen bleiben unübersetzt.
- Beiträge sind kurze Punkte im Aktiv, je mit einem Verb beginnend, ohne "Ich".
